# PR Workflow Guide

This fork is configured to keep your personal data private while contributing to the main UsTaxes project.

## Creating Pull Requests

### 1. Keep your fork updated

```bash
# Fetch latest from upstream
git fetch upstream

# Update your main branch
git checkout master
git merge upstream/master
git push origin master
```

### 2. Create a feature branch

```bash
# Always branch from master for clean PRs
git checkout master
git checkout -b feature/your-feature-name
```

### 3. Make your changes

- Write code
- Test thoroughly
- Commit with clear messages

### 4. Before creating PR

```bash
# Check for any personal files
git status

# Verify no personal data is staged
git diff --cached

# Push to your fork
git push origin feature/your-feature-name
```

### 5. Create PR on GitHub

- Go to https://github.com/ustaxes/UsTaxes
- Create PR from your fork's feature branch
- Fill out the PR template
